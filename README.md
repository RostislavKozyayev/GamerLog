# 🎮 GamerLog — Каталог видеоигр и трекер личной библиотеки

**GamerLog** — многостраничное одностраничное веб-приложение (SPA), разработанное на **React** с использованием **React Router DOM**. Платформа позволяет изучать каталог видеоигр, следить за новинками и анонсами, а после регистрации — вести собственный список игр по категориям и просматривать персональную статистику.

---

## Основной функционал

* **Главная страница**:
  * Интерактивный слайдер избранных игр с автопрокруткой и прогресс-баром (`Swiper`).
  * Тематические подборки: *«Популярные игры»*, *«Новинки»* и *«Анонсы игр»* с автоматической фильтрацией по дате выхода.
* **Каталог игр**:
  * Живой поиск по названию игры или студии-разработчику.
  * Кастомные выпадающие фильтры по **жанрам** (с внутренним поиском), **году выпуска**, **рейтингу Metacritic** и **статусу выхода**.
  * Сортировка по рейтингу, дате релиза и алфавиту.
* **Детальная страница игры**:
  * Подробная информация об игре (описание, рейтинг Metacritic, дата выхода, студия, жанры, статус релиза).
  * Управление статусом игры в личной библиотеке для авторизованных пользователей.
* **Личная библиотека** *(защищённый маршрут)*:
  * Распределение игр по 5 категориям: **«Играю»**, **«Пройдено»**, **«Хочу поиграть»**, **«Отложено»**, **«Брошено»**.
  * Фильтрация по вкладкам категорий с подсчётом количества игр.
* **Личный кабинет и авторизация** *(защищённый маршрут)*:
  * Регистрация и вход с клиентской валидацией форм.
  * Хранение пользователей, активной сессии и личной библиотеки в `localStorage` через `Context API`.
  * Вложенные маршруты (`Outlet`): **Статистика** (сводка по категориям с прогресс-барами, средний рейтинг библиотеки, топ любимых жанров) и **Настройки профиля**.
* **Адаптивный интерфейс**:
  * Поддержка десктопов, планшетов и смартфонов (выдвижное бургер-меню, адаптивные сетки и плавные CSS-анимации).

---

## Стек технологий

* **React 18** (функциональные компоненты, хуки `useState`, `useEffect`, `useMemo`, `useRef`, `useContext`)
* **React Router DOM** (`BrowserRouter`, `Routes`, `Route`, `Outlet`, `NavLink`, `useParams`, `useNavigate`, `useSearchParams`)
* **Swiper** — интерактивные слайдеры на главной странице
* **CSS3** — Flexbox, CSS Grid, медиа-запросы, кастомные переменные и `@keyframes`-анимации
* **Vite** — сборка проекта и сервер разработки

## Запуск проекта локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Перейдите в папку проекта и установите зависимости:
   ```bash
   cd gamerlog
   npm install
   ```
3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
4. Откройте в браузере адрес, указанный в терминале (обычно `http://localhost:5173`).

## Структура проекта

```text
src/
├── assets/          # Иконки и логотип
├── components/      # Переиспользуемые компоненты (Header, Footer, GameCard, ProtectedRoute и др.)
├── context/         # Глобальное состояние авторизации и библиотеки (AuthContext)
├── data/            # Локальная база данных игр (gamesData.js)
├── pages/           # Страницы приложения (HomePage, CatalogPage, GamePage, LibraryPage, ProfilePage и др.)
├── App.jsx          # Настройка маршрутизации и защищённых роутов
├── main.jsx         # Точка входа приложения
└── index.css        # Глобальные стили, анимации и адаптивная вёрстка
```
